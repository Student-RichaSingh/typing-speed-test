# Typing Speed Test

A web application that helps users practice typing and measure their typing performance.

**Project Status: In Progress** 

Core features are implemented, and I am continuing to improve the functionality, responsiveness, and user experience.

## Features

* Multiple difficulty levels: Easy, Medium, and Hard
* Timed and passage-based typing modes
* Words Per Minute (WPM) calculation
* Typing accuracy tracking
* Responsive interface for different screen sizes

## Tech Stack

* HTML
* CSS
* JavaScript
* JSON

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension.
